# 💊 Pharmacy Management System

A simple and efficient Pharmacy Management System designed to help manage sales, inventory, and staff with ease.

---

## 🚀 Features
- Secure login for admin and staff.
- Manage sales medicines and customers.
- Dashboard with statistics and reports.
- User roles and permissions support.

---

## 🛠️ Technologies Used
- **Node.js** and **Express.js**
- **MySQL**
- **EJS** for frontend rendering
- **Bootstrap** styling
- **dotenv** for environment variable management

---

## ⚙️ How to Run Locally
1. Clone the repository:
   git clone https://github.com/nabil-assi/Pharmacy-Managment-System.git
   Navigate into the project folder:

2. cd pharmacy



npm install express
npm install dotenv
npm install express-ejs-layouts
npm install express-session
npm install bcrypt


 
npm nodemon app.js


Open your browser and go to:

http://localhost:3000/login
